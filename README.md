# ecom-image-prompt-library

Version: **v0.0.1**

A practical prompt and workflow library for e-commerce product image generation.

中文：电商商品图 AI 提示词、分类树与实战案例库。

## What This Project Includes

- Amazon Best Sellers category framework
- Multi-level category taxonomy
- E-commerce image prompt templates
- Bilingual English-Chinese prompt system
- Practical prompt cases
- One-image-per-prompt rules
- Anti-collage rules
- Quality checklist
- Public/private data separation rules
- Versioned release workflow

## Important Rule

Do not publish private brand names, ASINs, Seller Central screenshots, advertising reports, sales data, cost data, supplier data, customer data, or copied competitor images.
