# Feature Image Prompt / 卖点图提示词

```text
Create a clean feature image for {product_type}.

Product:
{product_description}

Feature:
{feature_angle}

Requirements:
- Focus on one feature only.
- Use short and simple callout text if needed.
- Do not use unverified claims.
- Do not add fake badges, fake certifications, fake ratings, or marketplace logos.
- Keep the product accurate and realistic.
- Generate one independent image only.
- Do not create collage, grid, 2-panel image, 4-panel image, 6-grid image, 9-grid image, multi-scene overview, split-screen layout, or storyboard sheet.

Style:
Clean premium e-commerce infographic, light background, realistic product details, minimal text.
```
