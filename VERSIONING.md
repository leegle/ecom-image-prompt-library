# Versioning Rules

Current version: **v0.0.1**

## Version Format

```text
v0.0.1
```

## Upgrade Rule

```text
v0.0.1
v0.0.2
v0.0.3
...
v0.0.999
v0.1.0
v0.1.1
v0.1.2
...
```

When the patch number reaches 999, the next version becomes `v0.1.0`.

## Files To Update On Every Release

- `README.md`
- `README_zh.md`
- `README_en.md`
- `VERSIONING.md`
- `CHANGELOG.md`
- package zip filename
- any future manifest or config file

## Release File Name

```text
ecom-image-prompt-library-v0.0.1-full.zip
```
