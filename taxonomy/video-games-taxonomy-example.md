# Video Games Taxonomy Example / 电子游戏 分类树示例

Source: public marketplace category framework and user-provided Best Sellers screenshots.

公开仓库只记录通用分类和产品类型，不保存品牌、ASIN、价格、评论数、卖家工具数据或真实商品图片。

## Level Structure / 层级结构

```text
Amazon Best Sellers
└── Video Games / 电子游戏
    ├── Accessories / 游戏配件
    │   └── controller charging dock
    │   └── gaming headset
    ├── Games / 游戏软件
    │   └── generic game cover concept
    │   └── game card mockup
    ├── Gaming Systems / 游戏系统
    │   └── game console stand
    │   └── portable console case
    ├── Online Game Services / 在线游戏服务
    │   └── subscription card concept
    │   └── digital code card
```

- Do not invent unconfirmed performance claims, dimensions, compatibility, or certifications.
