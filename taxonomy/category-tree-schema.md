# Category Tree Schema / 分类树字段规范

| Field | 中文 | Description |
|---|---|---|
| node_id | 节点ID | Unique ID |
| parent_id | 父级ID | Parent node ID |
| level | 层级 | L0, L1, L2, L3, L4, L5 |
| name_en | 英文名称 | English name |
| name_zh | 中文名称 | Chinese name |
| slug | 文件夹名 | GitHub-friendly folder name |
| source_type | 来源类型 | public_framework, user_screenshot, manual |
| status | 状态 | placeholder, planned, in_progress, done |
| example_product_types | 示例产品类型 | Generic examples only |
| case_folder | 案例目录 | GitHub folder path |
| notes | 备注 | Compliance notes |
