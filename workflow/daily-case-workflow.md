# Daily Case Workflow / 每日案例流程

1. Pick one category / 选择一个类目
2. Pick one product type / 选择一个产品类型
3. Create one bilingual case / 创建一个双语案例
4. Generate one image at a time / 一次只生成一张图
5. Check with quality checklist / 用质检清单检查
6. Save image and prompt / 保存图片和提示词
7. Update CHANGELOG / 更新日志
8. Upgrade version number / 升级版本号
