# Public vs Private Data Rules / 公开与私有数据规则

## Public Repository Can Include

- Generic category names
- Generic product types
- Generic prompt templates
- Generic scene examples
- Compliance notes
- Quality checklists

## Public Repository Must Not Include

- Private brand names
- ASINs
- Seller Central screenshots
- Advertising reports
- Sales data
- Cost data
- Supplier information
- Private product photos
- Competitor image copies
- Third-party logos unless permitted
