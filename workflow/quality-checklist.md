# Image Quality Checklist / 图片质量检查清单

## Product Accuracy / 产品准确性

- Product type is correct / 产品类型正确
- Product color is correct / 产品颜色正确
- Product quantity is correct / 产品数量正确
- Product material is realistic / 产品材质真实
- Product scale is realistic / 产品比例真实
- No distorted logo or random text / 没有变形 Logo 或乱文字

## Compliance / 合规

- No fake badges / 没有虚假徽章
- No fake certifications / 没有虚假认证
- No fake ratings / 没有虚假评分
- No marketplace logos / 没有电商平台 Logo
- No unverified claims / 没有未经确认的宣传
- No copied competitor images / 没有复制竞品图片

## Anti-Collage / 防拼图

- One independent image only / 只生成一张独立图片
- No 6-grid / 没有六宫格
- No 9-grid / 没有九宫格
- No multi-scene overview / 没有多场景合集
