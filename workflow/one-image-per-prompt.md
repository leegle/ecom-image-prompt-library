# One Image Per Prompt / 一个提示词只生成一张图

One prompt should create one independent image only.

## Correct

```text
Generate Case 001 Main Image.
One independent image only.
Do not create collage, grid, 6-grid image, 9-grid image, or multi-scene overview.
```

## Wrong

```text
Generate 6 product images in one picture.
```

中文规则：一个提示词只生成一张独立图片。不要一次让 AI 生成 6 张图，否则容易变成六宫格、九宫格或拼图。
