# Translation Style Guide / 翻译规范

## Basic Rules

1. Folder and file names use English.
2. Markdown content can be bilingual.
3. Do not add unconfirmed claims during translation.
4. Do not translate private brand data into public files.

## Common Terms

| English | 中文 |
|---|---|
| Main Image | 主图 |
| Lifestyle Image | 场景图 |
| Feature Image | 卖点图 |
| Size Chart | 尺寸图 |
| A+ Banner | A+ 图 |
| Ad Banner | 广告图 |
| Negative Prompt | 反向提示词 |
| Quality Checklist | 质量检查清单 |
| One independent image only | 只生成一张独立图片 |
| Do not create collage | 不要拼图 |
